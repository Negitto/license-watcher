# 鮫洲試験場 学科試験 空き状況チェッカー

警視庁の運転免許手続予約サイトで、鮫洲試験場の学科試験の
空き状況(残席数)を自動チェックし、空きが見つかったら通知するツールです。

**重要:** この開発環境はネットワークアクセスできないため、
`check.js` は実際のサイトで動作確認していません。
初回はローカル(ご自身のMacBookなど)で `headless: false` にして、
目視で動きを確認してから GitHub Actions に載せてください。

## セットアップ手順

### 1. ローカルで動作確認

```bash
git clone <このリポジトリ>
cd license-watcher
npm install
npx playwright install chromium
```

`check.js` の `chromium.launch({ headless: true })` を
一時的に `headless: false` に変えて実行し、実際にブラウザが
正しい画面まで進むか確認してください。

```bash
node check.js
```

### 2. 確認・調整が必要な箇所

サイトの実際のJS挙動(自動遷移のタイミングなど)によっては
セレクタや待機処理の調整が必要です。特に以下を確認してください。

- `typeChoice=11`(空き状況カレンダー)を選んだ後、自動で次のページに
  進むか、「進む」ボタンを押す必要があるか
- カレンダーの月をまたぐ必要がある場合、「次」ボタン
  (`.ui-datepicker-next`)をクリックして翌月に進む処理を追加する必要あり
  (現在のスクリプトは今月分のみ確認する簡易版です)
- 日付クリック後、受付時間リストが更新されるまでの待機時間
  (`page.waitForTimeout(800)`)が短すぎ/長すぎないか

### 3. 通知先の設定

現状は [Pushover](https://pushover.net/) 向けの通知処理のみ入っています
(スマホに直接プッシュ通知が来る無料〜低価格のサービスです)。
LINEやメールに変えたい場合は `notify()` 関数を書き換えてください。

### 4. GitHub Actionsへの登録

1. このディレクトリをGitHubリポジトリにpush(空き状況の詳細が
   外部に見えても問題なければpublicリポジトリで無料枠が実質無制限)
2. リポジトリの Settings → Secrets and variables → Actions で
   `PUSHOVER_TOKEN` と `PUSHOVER_USER` を登録
3. `.github/workflows/check.yml` が自動で5分おきに実行されます
   (Actionsタブから手動実行も可能)

## 監視ロジックの前提(確認済みのDOM構造)

- カレンダーの日付セルは、クリック可能(`<a data-date>`あり)か
  不可(`ui-datepicker-unselectable`クラス)かで分かれる
- クリック可能でも実際は満席のことがあるため、日付クリック後に
  表示される受付時間リストの「残り○名」の数字で最終判定する
- 受験場所の選択パスは:
  「空き状況カレンダー」→受験項目「教習所卒業等」→
  免許保有形態「免許証のみ」→受験場所「鮫洲試験場」

## 注意事項

- このツールは**空き検知・通知のみ**を行います。実際のキャンセル・
  新規予約操作は安全のため手動で行ってください(サイト側が
  既存予約と新規予約の同時保持を許可しない仕様のため)。
- アクセス過多によるBot対策・一時ブロックを避けるため、
  チェック間隔は5分以上を推奨します。
